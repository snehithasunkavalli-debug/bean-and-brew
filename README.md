# Bean & Brew — Artisan Coffee Roastery & Café Website

A fully functional, highly responsive, and aesthetically pleasing multi-page website built as part of the **Digital Solutions Consultant Assignment**.

## 🌐 Live Pages Included
- **Home (`index.html`):** Hero, value pillars, signature drink carousel, live operating hours badge, interactive 3-step roast finder quiz, testimonials, and newsletter.
- **Café Menu & Online Ordering (`menu.html`):** Live filtering, real-time search, cupping notes modal, grind preferences, and calibration brew guide.
- **Our Story & Roastery (`about.html`):** Founding narrative, interactive 6-stage farm-to-cup timeline, sustainability dashboard, and team bios.
- **Table Reservations & Workshops (`reservations.html`):** Table booking with instant VIP reservation pass generator (print & calendar reminder), plus hands-on barista workshop RSVPs.
- **Coffee Beans & Gear (`shop.html`):** Bagged whole bean coffees with roast level tags, grind selector, subscription club details, and coffee storage tips.
- **Visit Us & Contact (`contact.html`):** Dual Portland locations, working inquiry form with character counting and success state, and interactive FAQ accordion.

## 🚀 How to Run
Simply double-click or open `index.html` in any web browser. No build tools or installations required!
